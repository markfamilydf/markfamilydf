# Markfamilydf Website

Professional responsive mobile technology website for **Markfamilydf**.

## Included
- Smartphone catalog
- Premium and value product filters
- Sample pricing
- Accessories section
- Interactive cart counter
- About section
- Newsletter form
- Mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish with GitHub Pages
Upload all files to the root of the `markfamilydf` repository.

Then go to:

**Settings → Pages → Deploy from a branch → main / root → Save**

The product names and prices are sample content and can be replaced with your actual inventory.
